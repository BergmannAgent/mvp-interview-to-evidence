# Research Artifact Scope

The [Organization Science special-issue call](https://orgsci.org/) requests a short
proposal, a technical appendix and a Git repository or equivalent prototype
artifact for Stage 1. The proposal is approximately 3-5 pages or 1,500-2,000 words
plus references. The call does not state a separate technical-appendix page limit
or a maximum number of repository files. It favors research prototypes rather
than production-ready applications.

This repository supplies the prototype, its technical documentation, synthetic
examples and reproduction materials. It does not replace the separate research
proposal or the authors' study-specific consent and ethics disclosures.

## Included

- TypeScript backend, three React applications and shared contracts.
- Docker build, database migrations and example environment configuration.
- Automated tests and explicit optional provider-test commands.
- Current technical appendix, measurement framework and workflow diagram.
- Versioned research instruments, source provenance and synthetic test results.

## Not Included In The Current Source Tree

Internal review logs, obsolete publication drafts, development plans, earlier
technical-report versions, private backup instructions and unused trial scripts
are not part of this submission-oriented tree. Runtime data, local environment
files, database dumps, audio files and build outputs are excluded from version
control.

## Anonymous Review

A personal GitHub account, commit history, branches and release assets are not
made anonymous by deleting files from the current tree. Use only the agreed
review artifact and check it independently before sharing. Do not change the
private development repository's visibility to expose a confidential backup.
See the [journal's review guidance](https://pubsonline.informs.org/authorportal/peer-review).

Original-language research records remain original-language records. English
presentation translations must not silently replace quotations or canonical data.
